Register a dimension tag for use as a falaise::quantity_t template parameter.

Expansion defines a struct for the tag, and a type alias for convenience e.g.

FALAISE_ADD_DIMENSION_TAG(length)
// Expansion results in definition of:
namespace falaise {
namespace config {
struct length {...};
using length_t = quantity_t<length>;
}
}
