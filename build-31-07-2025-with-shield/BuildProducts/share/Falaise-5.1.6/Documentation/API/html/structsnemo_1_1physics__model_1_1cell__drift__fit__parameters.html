double snemo::physics_model::cell_drift_fit_parameters::raw_eval ( const double &  radial_distance_,
const int  error_ = 0 
) const

Evaluate the drift time associated to a given radius using formula in DocDb #5839, p. 25, eq. 16. The model does not take into account possible angular assymmetry (see DocDb #5839, section p.28-30, fig. 24).

  • radius_ The radial distance to the central anode wire
  • error_ The error mode (0 : central value, -1 : -1 sigma value, +1 : +1 sigma value)
    Returns
    the drift value associated to the error mode (for details see see DocDb #5839: p. 23, fig. 14; p. 25, fig. 17; p. 28, fig. 21-22)
