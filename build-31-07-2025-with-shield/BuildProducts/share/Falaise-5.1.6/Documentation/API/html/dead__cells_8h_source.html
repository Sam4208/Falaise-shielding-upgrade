94  /*!\brief Class containing the functions to interact with the bad cells
95  *
96  * Class used to provide a Falaise service for the problematic (bad) cells in the SuperNEMO Tracker.
97  * The status of Trackers Geiger cells with problems will be stored
98  * in the CDB. Reconstruction modules can use this information.
99  * Each cell is defined by its coordinates (side,layer,column) and
100  * has a fixed status assigned depending on the encountered problem.
101  * The IOV of the status will be defined knowing the unique run number.
102  * The class defines the data structure used to describe a cell and
103  * includes functions to get informations about the status of a specific cell.
104  * A vector of cells is created which can be used in Falaise for other purposes.
105  *
106  * At the moment the bad cells are read from a column based text file
107  * given as input which should be in the format (side, layer, column, status);
108  * this will be replaced by a DB interface.
109  *
110  * Example of usage:
111  * ```cpp
112  * datatools::service_manager dummyServices{};
113  * datatools::multi_properties config;
114  * config.add_section("dead_cells_svc", "snemo::dead_cells_svc");
115  * dummyServices.load(config);
116  * dummyServices.initialize();
117  *
118  * snemo::service_handle<snemo::dead_cells_svc> DC_SVC{dummyServices};
119  *
120  * DC_SVC->LoadCells("cells_test.txt");
121  * snemo::cell_id cid(0,2,4);
122  * std::cout << "Side: " << cid.GetSide() << std::endl;
123  * std::cout << "Cell Status of 0,2,4: " << static_cast<int>(DC_SVC->CellStatus(cid,100)) << std::endl;
124  * std::cout << "Is 0,2,4 a dead cell?: " << DC_SVC->isADeadCell(cid,100) << std::endl;
125  * ```
126  */
