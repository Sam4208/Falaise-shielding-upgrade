Detailed Description

This bit mask locate the positions of neighbourg cells with HV off with respect to a given cell used as a reference:

Example: for a cell with two of its four neighbour cells with HV off, the associated 'neighbour_cells_off_pattern' bitset is thus: off_cell_direction::front | off_cell_direction::right

                :
              right
    +-------+-------+-------+  
    |       | HV off|       |
    |   o   |   o   |   o   |
    |       |       |       |
    +-------+-------+-------+
    | HV on |   :   | HV off|
