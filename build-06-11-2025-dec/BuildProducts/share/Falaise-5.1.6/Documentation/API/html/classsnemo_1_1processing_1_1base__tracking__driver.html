Initialize the clusterizer through configuration properties

Example of supported configuration properties:

Verbosity:

verbosity : string = "debug"

Service requirements:

services.geometry : boolean = true services.calo_locator : boolean = false services.xcalo_locator : boolean = false services.gg_locator : boolean = false services.cell_status : boolean = true services.om_status : boolean = false

Masking rules for Geiger cells:

cell_id_mask_rules : string = "..."

Tracker pre-clusterizer preprocessing:

TPC.delayed_hit_cluster_time : real as time = 10.0 us TPC.processing_prompt_hits : boolean = true TPC.processing_delayed_hits : boolean = true TPC.split_chamber : boolean = true
